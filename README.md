# G.E.N.E

> **AIが変わっても、あなたの対話と思考まで失う必要はない。**

G.E.N.Eは、AIとの対話を一時的なChatで終わらせず、話者、由来、原文、文脈を保持したローカル資産として記録し、Operator自身が必要な記憶・知識・参考情報を現在のLLMへ再接続するためのローカルAI対話環境です。

**人間側に、AIとの継続性を作る。**

---

## G.E.N.Eについて

G.E.N.Eは、LLMモデル本体ではありません。

OllamaなどのローカルLLM環境へ接続し、次の情報をOperator自身の管理下で運用します。

* Persona
* History
* Summary
* Knowledge
* Reference

G.E.N.Eは、AIとの対話を一時的なChatから、再利用可能なローカル資産へ変えることを目的としています。
