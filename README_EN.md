# G.E.N.E

[日本語](./README.md)

> **Even if the AI changes, you do not need to lose your dialogue and thought with it.**

**Create continuity with AI on the human side.**

G.E.N.E is a local AI dialogue environment for Windows x64 that records and operates AI dialogue as local data while preserving speaker identity, origin, original text, and context rather than treating dialogue as temporary chat.

G.E.N.E is not an LLM. Text generation requires a separate external local LLM environment, such as Ollama, and an available model.

## Main Functions

- Connection to an external local LLM environment
- Creation, selection, and management of Personas
- Storage and review of dialogue history
- Creation, storage, and reuse of summaries
- Registration and use of Knowledge
- Registration and use of Reference files as external materials
- A local data structure that preserves speaker identity, origin, original text, and context

For details and current limitations, see [Known Limitations](./docs/KNOWN_LIMITATIONS_EN.md).

## Before Use

- Do not use G.E.N.E as the only storage location for important data. Maintain backups.
- Compatibility with every combination of runtime, model, operating system, and hardware is not guaranteed.
- Changing the model does not guarantee identical answers, behavior, or personal identity.
- Accuracy, completeness, and safety of AI output are not guaranteed.
- Verify the file size and SHA-256 of an obtained archive before extraction or execution.
