## 1. Purpose and Basic Principle

本Privacy Noticeは、GeneSISがG.E.N.Eの配布、Founder資格の確認、公式情報の公開、問い合わせ対応およびSecurity対応に伴って、実際に受け取る情報の取扱いを説明するものです。

GeneSISは、個人開発・個人運営として、利用目的に必要な範囲を超える情報を求めず、GeneSISが実際に受け取った情報をOperator本人が直接管理します。

GeneSISは、BOOTH、GitHub、Googleその他の外部Platformが保有する利用者情報全体を取得、管理または支配するものではありません。

GeneSISが取り扱う情報は、各PlatformからGeneSISへ実際に表示される情報、または利用者本人がGeneSISへ送信した情報に限られます。

- **Brand / Operator:** GeneSIS: Concept Engineer's HQ.

GitHub Issues、GitHubの非公開脆弱性報告機能、SNS上の投稿、Reply、MentionまたはDirect Messageでは、運営者情報の開示請求を受け付けません。

## 3. Information Channels

GeneSISは、情報の性質に応じて受付経路を分離します。

### 3.1 GitHub Repository

GitHub Repositoryは、Privacy Notice、Support Policy、Security Policy、Release情報、検証情報その他の公式技術文書を公共へ公開する場所です。

GitHub Repositoryに方針文書を掲載することは、すべての問い合わせ、個人情報請求または非公開連絡をGitHub上で受け付けることを意味しません。

### 3.2 GitHub Issues

GitHub Issuesは、公開可能な通常の技術的不具合、Documentationへの指摘および開発上のFeedbackを受け付ける公開領域です。

GitHub Issuesでは、原則として次の情報を扱います。

- 対象VersionまたはBuild
- OSその他の使用環境
- 使用しているローカルLLM環境またはModel
- 問題の内容
- 再現手順
- 期待した動作
- 実際の動作
- 公開可能なLog、画像または補足資料
- Documentationへの指摘
- 製品改善に関する意見

GeneSISは、GitHub Issuesを購入者管理、Founder資格の照合、顧客名簿の作成または利用者個人の追跡を目的として使用しません。

通常の技術的評価では、原則として「誰が投稿したか」ではなく、製品上で何が起きたか、再現可能か、開発へ活用できるかを確認します。

個人情報、購入情報、Founder資格情報、私的な対話履歴、Persona情報、利用条件や権利に関する非公開情報、認証情報または未修正のSecurity問題を投稿しないでください。

### 3.3 GitHub Private Vulnerability Reporting

このRepositoryでGitHubの非公開脆弱性報告機能が有効になっている場合、同機能は、G.E.N.Eに関する未修正の脆弱性その他のSecurity上の懸念を非公開で受け付ける技術的報告経路として使用します。

同経路で扱う対象は、主として次の情報です。

- 対象VersionまたはBuild
- 脆弱性またはSecurity上の懸念の内容
- 再現条件
- 想定される影響
- 関連するLog、画像または添付File
- 修正前に公開すべきでない技術情報
- 調査および連絡の履歴

GitHub Usernameまたは報告者が任意で提供した連絡情報が付随する場合がありますが、これらはSecurity問題の確認、調査、影響評価および連絡のためにのみ使用します。

同経路は、一般的な個人情報請求、運営者情報の開示請求、購入、Founder資格、利用条件、権利または製品Securityと無関係な個人的事情の受付には使用しません。

詳細は、[Security Policy](../SECURITY.md)を確認してください。

### 3.4 GeneSIS Official Gmail

GeneSIS公式Gmailは、個人の識別または一対一の非公開対応が必要な事項を受け付ける正式な窓口です。

主な受付対象は次のとおりです。

- 個人情報の取扱いに関する問い合わせ
- 運営者情報の開示請求
- 本人情報の開示、訂正、削除または利用停止等の請求
- 購入およびFounder資格の照合
- 利用条件、配布条件および権利に関する問い合わせ
- 公開に適さない技術的不具合
- GitHubの非公開脆弱性報告機能を利用できない場合のSecurity報告
- その他の非公開連絡

### 3.5 BOOTH

BOOTHは、G.E.N.Eの正式配布、Founder Supportの受付、購入記録およびFounder成果物の提供に使用します。

Founder資格の確認における正本は、原則としてBOOTH上のFounder Support商品の購入記録です。

GeneSISは、BOOTHがショップ運営者へ実際に表示する範囲の注文関連情報のみを取り扱います。

### 3.6 Social Media

SNSは、Release告知、更新情報および公式導線の案内に使用します。

SNS上の投稿、Reply、MentionまたはDirect Messageは、正式なSupport、Privacy、Founder照合、購入、権利またはSecurity報告の受付経路ではありません。

## 4. Information GeneSIS May Handle

GeneSISは、次の情報を必要な範囲で取り扱うことがあります。

### 4.1 BOOTHから確認できる情報

- BOOTH上のユーザー識別コード
- 注文番号
- 購入した商品
- 購入日時または購入時期
- 注文、取消しまたは返金等の状態
- BOOTH上のメッセージ
- BOOTHがショップ運営者へ表示するその他の注文関連情報
- Founder資格の照合のため、利用者本人が任意で送信した必要最小限の情報

BOOTHのユーザー識別コードは、コード単体で利用者の実名等を特定するための情報ではありません。

ただし、GeneSISは、注文情報、メッセージその他の情報と関連付けて取り扱う場合があるため、適切に管理します。

GeneSISがBOOTH利用者の登録情報全体、Password、完全な決済情報またはPlatform内部情報へアクセスするものではありません。

### 4.2 GitHub上で公開された情報

- GitHub Username
- 利用者が自ら公開したProfile情報
- Issue、Commentその他の公開投稿
- 投稿日時
- 利用者が添付したLog、画像またはFile

これらは主として、製品の使用情報、不具合情報、Documentationへの指摘および開発上のFeedbackとして取り扱います。

GitHub Username、公開Profileその他の情報は、その内容および他の情報との組合せによって特定の個人を識別できる場合、個人情報に該当することがあります。

GeneSISは、公開されていることのみを理由として、これらの情報を目的なく収集、照合または再利用しません。

GeneSISは、GitHub上の公開情報を用いて、利用者の実名調査、購入者との照合、行動Profileの作成または顧客分析を行いません。

### 4.3 GitHubの非公開脆弱性報告で受け取る情報

- GitHub Username
- 報告者が任意で提供した連絡情報
- 対象VersionまたはBuild
- Security上の懸念の説明
- 再現条件
- 影響範囲
- Log、画像または添付File
- 調査および連絡の履歴

これらの情報は、Security上の懸念の確認、調査、影響評価および対応のために使用します。

Founder資格、購入記録、一般的なPrivacy請求または顧客管理には使用しません。

詳細は、[Security Policy](../SECURITY.md)を確認してください。

### 4.4 GeneSIS公式Gmailへ送信された情報

- 送信元メールアドレス
- 表示名
- 件名および本文
- 添付File
- 問い合わせ日時
- 問い合わせおよび回答の履歴
- Founder資格の照合に必要な注文番号その他の情報
- 不具合調査またはSecurity対応に必要な情報
- 本人が任意で送信したその他の情報

調査または照合に不要な対話履歴全体、Persona情報、Password、2段階認証Code、Backup Code、API Key、秘密鍵、完全なクレジットカード情報または第三者の個人情報を送信しないでください。

## 5. Purposes of Use

GeneSISは、取得した情報を主に次の目的で使用します。

- 購入記録およびFounder資格の確認
- Founder成果物その他の公式成果物の提供
- 問い合わせへの対応
- 技術的不具合の確認、再現および改善検討
- GitHub上で寄せられた製品情報およびFeedbackの開発への活用
- Security上の懸念への対応
- 利用条件、配布条件、権利および個人情報に関する確認
- なりすまし、不正利用、権利侵害または安全上の問題への対応
- GeneSISの公式運用に必要な記録

GeneSISは、取得した情報を次の目的には使用しません。

- 個人情報または購入者情報の販売
- 本Privacy Noticeに記載した利用目的と合理的な関連性を有しない広告配信
- 利用者の行動分析またはMarketing Profileの作成
- 外部企業との共同利用
- 支援額に基づく利用者の序列化
- 本Privacy Noticeに記載した利用目的と合理的な関連性を有しない営利利用

## 6. Separation and Linking of Information

Founder資格および購入記録の照合は、原則として、BOOTH上の購入記録とGeneSIS公式Gmailへ本人が送信した情報との間で行います。

GitHub上の公開情報を、Founder資格または購入記録の照合には使用しません。

GeneSISは、GitHub上の公開投稿を、BOOTHの購入記録またはGeneSIS公式Gmailの問い合わせ情報と通常は結び付けません。

GitHub上の意見や通常の不具合情報は、投稿者個人の顧客情報ではなく、公開された製品情報および開発上のFeedbackとして取り扱います。

ただし、利用者本人が特定のIssue、非公開脆弱性報告または問い合わせとの関連付けを明示的に依頼した場合は、その依頼に必要な範囲で確認することがあります。

また、次の場合に限り、必要最小限の範囲で複数の経路にある情報を確認することがあります。

- Security上の懸念の調査に必要な場合
- なりすまし、権利侵害または不正利用への対応に必要な場合
- 法令または公的機関からの適法な要請への対応に必要な場合

## 7. External Platforms and Human Outsourcing

GeneSISは、BOOTH、GitHubおよびGoogle / Gmailを、配布、公式情報公開、Feedback受付および非公開連絡のための外部Platformとして利用します。

各Platformは、それぞれの利用規約およびPrivacy Policyに基づき、独立して利用者情報を取り扱います。

GeneSISは、各Platformが保有する利用者情報全体を取得、管理または支配しません。

各Platformの運用により、情報が日本国外のServerで保存または処理される場合があります。

各Platformによる情報の取扱い、保存場所および国際的なデータ移転には、各Platformが定めるPrivacy Policyが適用されます。

GeneSISも、外部Platformの利用に伴う情報の取扱いについて、適用法令に従い、取り扱う情報の性質、量およびリスクに応じた必要かつ適切な安全管理措置を講じます。

GeneSISは現在、Founder資格の照合、成果物の提供、問い合わせ対応または利用者情報の管理を、外部のSupport会社、事務代行業者その他の人的Serviceへ通常業務として委託していません。

将来この取扱いを変更する場合は、必要に応じて本Privacy Noticeを更新します。

ただし、本人の同意がある場合、法令上認められる場合、権利または安全の保護に必要な場合、または法的専門家への相談が必要な場合は、必要最小限の情報を適法な範囲で取り扱うことがあります。

GeneSISは、個人情報を第三者へ販売しません。

## 8. Storage and Security

GeneSISは、取得した情報を、利用目的の達成、Founder資格の確認、成果物の提供、問い合わせ対応、Security対応、権利保全または法令上の必要性がある期間に限って保管します。

合理的な保管の必要性がなくなった情報は、技術的および運用上可能な範囲で削除または整理します。

Backup、メールArchive、Gitの履歴または外部Platformの仕様により、削除後も一定期間、情報の複製が残る場合があります。

GeneSISは、個人開発の規模と取り扱う情報の性質に応じて、次の対策を行います。

- 管理用Accountと公開窓口の分離
- 2段階認証その他のAccount保護
- Passwordの使い回し防止
- Access範囲の必要最小化
- 不要な個人情報の取得抑制
- 公開Issue、非公開脆弱性報告および公式Gmailの経路分離
- 不要となった添付Fileおよび記録の整理
- 安全性、安定性および互換性を考慮したSoftwareと利用Serviceの適切な更新

GeneSISから、Password、2段階認証Code、Backup Code、API Keyまたは秘密鍵の提出を求めることはありません。

## 9. Information Security Incidents

GeneSISが取り扱う情報について、漏えい、滅失、毀損、不正Accessまたは不正利用が発生し、またはそのおそれを確認した場合、GeneSISは影響範囲および原因を確認し、可能な範囲で拡大防止および再発防止の措置を行います。

適用法令上、監督機関への報告または本人への通知が必要となる場合は、必要な対応を行います。

外部Platform上で発生したIncidentについては、当該Platformの案内および対応状況を確認し、GeneSISが対応可能な範囲で利用者への案内その他の措置を行います。

## 10. Requests Concerning Personal Information

本人または正当な代理人は、適用法令の範囲で、GeneSISが保有する本人の情報について、開示、訂正、追加、削除、利用停止その他の請求を行える場合があります。

請求は、GeneSIS公式Gmailでのみ正式に受け付けます。

メールの件名を次のようにしてください。

```text
[Privacy Request]
```

本文には、請求の種類および対象情報を可能な範囲で記載してください。

GeneSISは、本人または正当な代理人からの請求であることを確認するため、GeneSISが既に保有する次の情報との照合を求める場合があります。

- BOOTHの注文番号
- BOOTH上のユーザー識別情報
- 過去の問い合わせに使用したメールアドレス
- GitHub Username
- 過去の問い合わせ日時または件名
- その他、対象情報を特定するための必要最小限の情報

Password、2段階認証Code、Backup Code、API Key、秘密鍵または完全な本人確認書類を、GeneSISからの具体的な案内なく送信しないでください。

現在、開示等の請求に関する手数料は設定していません。

将来、手数料を設定する場合は、事前に本Privacy Noticeまたは別途指定する請求手続で案内します。

本人確認ができない場合、第三者の権利利益を害するおそれがある場合、法令上対応できない場合、またはGeneSISが対象情報を保有していない場合は、請求の全部または一部へ対応できないことがあります。

BOOTH、GitHub、Googleその他のPlatformが独自に保有する情報については、各Platform提供者へ直接請求する必要があります。

## 11. International Access

本Privacy Noticeは、日本の個人情報保護法を中心として作成しています。

日本国外からRepositoryまたは配布ページを閲覧・利用できることのみをもって、GeneSISが特定の国または地域を対象として商品またはServiceを提供していることを意味するものではありません。

GeneSISの情報取扱いへ特定地域の強行法規が適用される場合は、必要に応じて地域別の追加Notice、英語版その他の対応を行います。
