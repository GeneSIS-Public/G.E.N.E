## 1. 取扱責任者

GeneSISは、1名のGeneSIS-Operatorが開発・運営する個人Projectです。

個人情報等の取扱い、問い合わせ対応、Founder照合、権利請求および外部回答に関する最終判断は、GeneSIS-Operatorが行います。

**GeneSIS公式窓口**

`genesis.official.poc@mail.com`

法令上必要となる追加情報は、適用法令および利用Platformの手続に従って提示します。

## 2. G.E.N.E本体とローカルData

G.E.N.Eは、利用者の端末上で動作するローカルAI対話環境です。

通常の利用において、GeneSISは次のDataを自動的に収集または受信しません。

- G.E.N.E内の対話履歴
- Persona
- Summary
- Knowledge
- Reference
- Prompt
- 接続Modelの入出力
- ローカルFileまたは保存Path
- API Keyその他の認証情報

利用者が不具合報告、問い合わせまたはSupportのために自ら送信した場合は、その送信範囲に限って取り扱います。

利用者は、送信前に不要な個人情報、認証情報、私的対話および第三者情報を削除または伏せてください。

## 3. 取得する可能性がある情報

GeneSIS-Operatorは、利用者の行動と利用するPlatformに応じて、次の情報を取得または閲覧する場合があります。

### 3.1 問い合わせ・Support

- 氏名、表示名またはHandle
- メールアドレス
- 問い合わせ本文
- 添付File
- Version、Build、OS、Runtime、Model等の技術情報
- Log、画面情報、再現手順
- 返信および対応履歴

### 3.2 BOOTH・Founder照合

- BOOTH上で表示される購入者情報
- 注文番号
- 商品名
- 購入時期
- 購入・Download・Messageに関するPlatform上の記録
- Founder資格の確認に必要な範囲の情報

GeneSIS-Operatorは、BOOTHの決済処理を直接行わず、クレジットカード番号等の完全な決済情報を取得しません。

### 3.3 GitHub

- GitHub上の公開Profile情報
- Issue、Comment、Reportおよび添付情報
- Private Vulnerability Reporting等を通じて送信された非公開情報
- Repository上の公開活動記録

GitHub Issuesは公開領域です。個人情報、認証情報、私的対話または未修正脆弱性の詳細を投稿しないでください。

### 3.4 note・Xその他の公式媒体

- 公開Profile情報
- Follow、Reaction、Reply、Mention、Comment等の公開情報
- 利用者が自ら公開または送信した内容

Xを含むSNS上のDirect Messageは、正式なSupport、Founder照合、Privacy請求またはSecurity報告の受付経路ではありません。

### 3.5 技術的記録

利用PlatformまたはメールServiceが、Access日時、IP Address、Device情報、Cookieその他の技術情報を処理する場合があります。これらは各PlatformのPrivacy Policyおよび設定に従って取り扱われます。

GeneSIS-Operatorが各Platformの保有情報すべてを取得または管理するものではありません。

## 4. 利用目的

取得した情報は、必要な範囲で次の目的に利用します。

- 問い合わせへの確認および回答
- 不具合、互換性、Security問題の調査
- 文書、Release、Known LimitationsおよびSupport案内の改善
- 公式配布物、購入記録およびFounder資格の確認
- EULA、Founder Termsその他の条件に関する対応
- Privacy・権利請求への対応
- 不正利用、Spam、脅迫、嫌がらせまたはSecurity上の危険への対応
- 法令上必要な対応
- GeneSISの開発・運営に必要な記録の維持

利用目的を変更する場合は、変更前の目的と合理的な関連性を有する範囲で行い、必要に応じて本書を更新します。

## 5. AIによる補助

GeneSIS-Operatorは、文書整理、翻訳、技術的検討または問い合わせ内容の整理を補助するため、AIを利用する場合があります。

非公開情報をAIで扱う場合は、目的に必要な範囲へ情報を削減し、必要に応じて匿名化または伏字処理を行います。Password、認証Code、秘密鍵、完全な決済情報等をAIへ入力しません。

Founder資格、権利、Privacy請求、Security対応その他の重要事項について、AIのみで最終判断または外部回答を行いません。最終判断と送信内容はGeneSIS-Operatorが確認します。

## 6. 第三者Platform・委託先

GeneSISは、運営上、次のような第三者Serviceを利用します。

- BOOTH
- GitHub
- note
- X
- Email Service
- AI Serviceを利用する場合の当該Service

利用者がこれらのPlatformを利用した場合、各Platform運営者も、その利用規約およびPrivacy Policyに基づいて情報を処理します。処理拠点が日本国外となる場合があります。

GeneSIS-Operatorは、法令に基づく場合、本人の同意がある場合、権利・安全の保護に必要な場合、または運営に必要なService提供者へ適切な範囲で取り扱いを委ねる場合を除き、個人Dataを第三者へ販売または不当に提供しません。

## 7. 保存と削除

情報は、利用目的の達成、対応履歴の維持、紛争・不正利用・Security対応および法令上必要な範囲で保存します。

保存期間は、情報の種類、対応内容、Platformの仕様および法令上の必要性によって異なります。

利用目的が終了し、保存の必要がなくなった情報は、合理的な範囲で削除または識別性を低減します。ただし、BOOTH、GitHub、note、Xその他のPlatformが保持する情報は、各Platformの仕様と手続に従います。

## 8. 安全管理

GeneSIS-Operatorは、取り扱う情報の性質と個人運営の規模に応じて、次のような安全管理を行います。

- Accountごとに適切なPasswordを使用する
- 利用可能な場合は2段階認証を使用する
- AccessできるAccount・端末・連携Appを限定する
- 不要な認証情報や機微情報を取得しない
- 公開情報と非公開情報を分離する
- 不要となった情報を整理・削除する
- Security上の問題を確認した場合に必要な対応を行う

Internetおよび外部Platformを利用する以上、完全な安全性を保証するものではありません。

請求時には、対象情報と希望する対応を明示してください。本人確認、第三者の権利保護、Securityおよび不正請求防止のため、必要最小限の確認情報を求める場合があります。
