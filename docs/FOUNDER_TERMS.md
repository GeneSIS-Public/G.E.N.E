## 第1条　目的とFounder Supportの性質

本参加条件書は、GeneSISがBOOTH上で提供する「Project: Code-NOAH Phase 1 Founder Support」（以下「Founder Support」といいます）について、参加条件、提供内容、FounderとGeneSISとの関係その他の必要事項を定めます。

Founder Supportは、G.E.N.E Alpha v1.0の上位版、機能追加版、優先Support契約、出資、融資または利益分配型の商品ではありません。

Founder Supportは、G.E.N.Eを入口として、GeneSISが進めるProject: Code-NOAH Phase 1の活動へ、購入者自身の意思によって明示的に参加・支援するための商品です。

## 第2条　用語およびPhaseの関係

本書では、次の意味で用語を使用します。

1. Project: Code-NOAH
   GeneSISが進めるProjectであり、G.E.N.EおよびProject配下で成立するProduct、Tool、Operationその他の成果物を含む開発・公開運用の基盤をいいます。

2. G.E.N.E
   Project: Code-NOAHの直系成果物としてGeneSISが開発するローカルAI対話環境およびその関連成果物をいいます。

3. Project Phase
   Project: Code-NOAH全体の開発・公開運用段階を示す区分をいいます。PhaseのAuthorityはProject: Code-NOAHにあります。

4. G.E.N.E Phase
   Project Phaseと同期して用いるG.E.N.E側のPhase表現をいいます。G.E.N.E Phaseは独立した別のPhase制度を構成せず、同番号のProject Phaseと同一の段階を示します。

5. Phase 1
   Project: Code-NOAH Phase 1をいいます。G.E.N.E側ではG.E.N.E Phase 1として同期表現され、現時点ではG.E.N.E v1.x系の開発・公開運用段階を含みます。

6. Phase成果物
   当該Project Phase中にProject: Code-NOAH配下で成立したProduct、Tool、Operationその他の成果物をいいます。Phase成果物であることだけを理由として、Founder Supportの提供対象となるものではありません。

7. Founder
   本書を確認し、BOOTH上のFounder Support商品を購入することで、Project: Code-NOAH Phase 1への参加・支援意思を明示した購入者をいいます。

8. Founder成果物
   本書に基づき、Phase 1 Founderへの後日提供対象として明示的に定める、O-type Generator Founder EditionおよびGene-ScrIbe ConSole Founder Editionをいいます。

9. Supplemental / Additional Deliverable
   Founder成果物とは別に、GeneSISがFounder Support購入者へ追加提供する対象として、BOOTH、Founder Support Informationその他の公式媒体で明示した成果物をいいます。ある成果物がPhase 1中に成立したことだけを理由として、Supplemental / Additional Deliverableとなるものではありません。

10. 追加支援
    BOOTHの購入手続におけるBOOSTその他、GeneSISが正式に案内する任意の金銭的支援をいいます。

Project: Code-NOAH配下のG.E.N.E以外の成果物は、別途明示しない限り独自のProject Phaseを持つものとして扱わず、それぞれのVersion、BuildまたはRevisionによって管理します。

## 第7条　開発順位と提供時期

1. Phase 1における開発、検証、運用、配布およびDocumentation整備は、Project: Code-NOAH全体の状況を踏まえて進行します。Founder成果物の配布調整は、Phase 1における主要な後続開発対象の一つとして扱います。

2. Security、重大な不具合、法令対応、配布環境の維持その他の緊急性が高い作業を先行する場合があります。

3. Founder成果物は既存の内部運用成果物を基礎とする場合がありますが、一般利用可能な状態にするため、内部固有情報の除去、UI・文言の調整、利用条件の整理、試験、Package化、権利確認およびRelease工程を必要とします。

4. GeneSISは一人のGeneSIS-Operatorが中心となって開発・運営しており、資金、生活基盤、健康、技術的問題、検証結果または外部Platformの事情によって開発期間が変動します。

5. Founder成果物の具体的な完成日、提供日、提供月または開発期間は保証しません。

6. 期限を優先するために、重大な品質、安全性または権利上の問題を認識した成果物を配布しません。

7. 一方で、定義した最小配布基準を満たした成果物は、不要に先延ばしせず正式Releaseする方針です。

8. Supplemental / Additional Deliverableは、Founder成果物の開発順位または提供義務を当然に置き換えるものではありません。個別の追加提供によって、第5条第3項に定めるFounder成果物の意味または定義を変更しません。

## 第12条　Founderという呼称と権利の非付与

Founderという呼称は、Project: Code-NOAH Phase 1の初期支援参加者であることを示す限定的な参加区分です。

G.E.N.E Phase 1はProject: Code-NOAH Phase 1と同期する表現であり、Founder資格はG.E.N.Eだけに限定された有料Edition資格を意味しません。

Founder Supportへの参加によって、次の地位または権利は付与されません。

- GeneSISまたはProject: Code-NOAHの所有権
- G.E.N.Eその他の成果物に関する知的財産権
- Source Codeまたは内部資料へのAccess権
- 共同経営者、共同開発者、共同著作者、従業員、業務委託者または代理人としての地位
- 株主、出資者、融資者または事業収益の分配を受ける者としての地位
- 利益分配請求権または議決権
- 開発方針、事業方針またはRelease判断の決定権
- 要望の実装請求権
- Project: Code-NOAH Phase 1中に成立するすべてのPhase成果物を受け取る権利
- Phase 2以降への自動参加権

Founder Supportは、金融商品、出資契約、利益分配型投資または共同事業契約ではありません。
