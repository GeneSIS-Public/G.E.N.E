### Release

| Item | Information |

| Release Record Signed Date | `2026-07-21` |

G.E.N.E Alpha v1.0 is the first official public release in Project: Code-NOAH Phase 1.

### Added

- G.E.N.E application for Windows x64
- A basic environment for recording and operating AI dialogue as local data
- Connection to an external local LLM environment such as Ollama
- Persona creation, selection, and management
- Storage and review of dialogue history
- Creation, storage, and reuse of summaries
- Registration and use of Knowledge
- Registration and use of Reference files as external materials
- A basic structure for preserving speaker identity, origin, original text, and context
- Local operation in which users manage dialogue data in their own environment
- The official G.E.N.E Alpha v1.0 distribution package
- The EULA, README, and other included documents
- Official release information, archive verification information, and Known Limitations

### Release Characteristics

- G.E.N.E is not an LLM and requires a separate external local LLM environment and model.
- The G.E.N.E application is distributed free of charge.
- Founder Support, BOOST, or other support status does not change the functions of the G.E.N.E application.
- The source code is not publicly released.
- The official archive is fixed and will not be changed while retaining the same filename.
- Later G.E.N.E v1.x releases will be distributed as separately versioned files.
